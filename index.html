Ethical Hacking

Ethical hacking is the practice of testing systems, networks, and applications to find security vulnerabilities before malicious hackers can exploit them. I use tools and techniques like penetration testing, vulnerability scanning, and exploitation frameworks to understand how real-world attacks happen and how to prevent them effectively.

Network Security

Network security focuses on protecting systems and data from unauthorized access, misuse, or attacks. I study firewalls, intrusion detection systems, packet analysis, and secure network design to understand how data flows and how to defend against threats like MITM attacks, sniffing, and spoofing.

Web Pentesting

Web penetration testing involves identifying vulnerabilities in web applications such as SQL injection, XSS, CSRF, and authentication flaws. I analyze how websites function internally and test them using tools like Burp Suite to find weaknesses and improve their security.

Python

Python is my go-to language for building cybersecurity tools and automation scripts. I use it to create scanners, automate tasks, and analyze data. It helps me develop real-world security tools like my SPPTI scanner and improve efficiency in testing processes.

CTF Challenges

Capture The Flag (CTF) challenges are practical cybersecurity exercises that improve problem-solving skills. I regularly solve CTF challenges related to cryptography, web security, reverse engineering, and forensics to sharpen my hacking mindset and technical skills.

Digital Forensics

Digital forensics involves investigating cyber incidents by analyzing system data, logs, and artifacts. I learn how to trace attacks, recover evidence, and understand how breaches happen. This helps in both defending systems and responding to cyber threats effectively.
